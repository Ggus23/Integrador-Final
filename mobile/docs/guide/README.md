# MentaLink Mobile App (Oasis Aesthetic)

Esta es la versión móvil nativa de MentaLink, construida con React Native y Expo.

## Características
- **Diseño Oasis**: Adaptación fiel del sistema de diseño editorial y minimalista.
- **Glassmorphism**: Efectos de desenfoque y capas tonales.
- **Tipografía**: Noto Serif y Manrope para un aire sofisticado.

## Instalación

1. Asegúrate de tener Node.js instalado.
2. Navega a la carpeta: `cd mobile`
3. Instala las dependencias: `npm install`
4. Inicia el proyecto: `npx expo start`

## Estructura
- `App.js`: Pantalla principal de registro emocional.
- `src/theme/colors.js`: Tokens de color del sistema Oasis.
