## 📊 ¿QUÉ SE IMPLEMENTÓ?

Una **visualización de correlación entre estrés y desempeño académico** usando regresión lineal.

```
┌──────────────────────────────────────┐
│   Nivel de Estrés (PSS Score)        │
│   (Eje X: 0-40)                      │
│                                      │
│    Desempeño                         │
│    Académico     •                   │
│    (Eje Y)    •     •    ╱╱╱ Línea  │
│              •       •  ╱   Regresión│
│            •       ╱  •             │
│          •     ╱    •  •            │
│        •   ╱      •   •             │
│      •╱        •      •             │
│    ╱        •         •             │
│          •         •  •             │
│                                     │
└──────────────────────────────────────┘

Ecuación: y = -1.847x + 105.32
R²: 75.8% de varianza explicada
Conclusión: A mayor estrés → Menor desempeño
```
